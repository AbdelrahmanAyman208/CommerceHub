# CommerceHub (كلية التجارة — المنصة التعليمية)

A high-performance, bilingual (Arabic RTL / English LTR) learning and exam platform built for faculty lecturers and up to ~1,000 students.

## 🌟 Key Features

- **Bilingual Interface:** Real-time toggle between Arabic (Cairo font, native RTL) and English (Inter font, LTR).
- **8-Digit Numeric Student IDs:** Auto-generated by a database sequence (`10000001`, `10000002`, ...). All students share the uniform 8-digit format.
- **Dynamic 50% Pass Mark:** Pass mark is always derived as 50% of total exam marks (e.g. 20-point exam requires 10 points to pass).
- **Strict Role Boundaries:**
  - **Doctor (Super Admin):** Complete system access and **exclusive permission to modify or override student grades**.
  - **Teaching Assistant (Admin):** Can manage courses, upload lecture PDFs, create exams, and broadcast announcements, but **cannot edit student grades**.
  - **Student:** View courses, read view-only PDFs, take timed exams, and inspect grades.
- **Academic Integrity Shield (Anti-Screenshot Protection):**
  - Right-click context menu disabled.
  - Print (Ctrl+P) and screenshot (PrintScreen) shortcuts intercepted.
  - Window blur detection: blurs content and displays a security overlay if the student leaves or switches tabs.
  - Hidden on print (`@media print`).
  - View-only PDF streaming (no download prompt).
  - Low-opacity diagonal watermarking stamped with student name and ID.
- **Exam Engine:**
  - Server-enforced countdown timer (`expires_at`).
  - Configurable attempts limit per exam.
  - Question and option randomization (Fisher-Yates).
  - Debounced autosave with visual status indicator.
  - BullMQ asynchronous grading queue with immediate fallback.
- **Bulk CSV Import:** Upload a CSV file with `name,email` columns to create hundreds of students at once. Each student is auto-assigned an 8-digit ID.
- **Theme Toggle:** Switch between Dark mode and Light/White mode.
- **Analytics & Reporting:**
  - Recharts dashboard with grade distribution histogram, pass/fail ratio (50% threshold), lecture engagement, and at-risk student monitoring.

## 🚀 Quick Start (Development)

```bash
# Start lightweight dev stack (~960 MB RAM budget)
docker-compose -f docker-compose.dev.yml up --build
```

- **Frontend:** [http://localhost:5173](http://localhost:5173)
- **Backend API:** [http://localhost:3000](http://localhost:3000)
- **Health Check:** [http://localhost:3000/health](http://localhost:3000/health)

### Default Seed Accounts:
- **Doctor (Super Admin):** `admin@commercehub.edu` / `admin123`
- **Teaching Assistant:** `assistant@commercehub.edu` / `admin123`
- **Student 1:** `10000001` (or `student1@commercehub.edu`) / `student123`
- **Student 2:** `10000002` (or `student2@commercehub.edu`) / `student123`

## 🚢 Production Deployment

```bash
docker-compose -f docker-compose.prod.yml up -d --build
```

Runs 2 API instances behind Nginx with PgBouncer connection pooling and tuned PostgreSQL. See [docs/deployment.md](docs/deployment.md) for complete details.
